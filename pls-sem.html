Yorum Paneli

Analiz sonrası otomatik yorum burada oluşur.

Veri Analiz Robotu, açık kaynak kütüphaneleri kullanılarak geliştirilen özel bir Python altyapısı aracılığıyla PLS-SEM analizlerini gerçekleştirmektedir. Yapısal modelde yol katsayıları En Küçük Kareler (Ordinary Least Squares – OLS) yöntemiyle tahmin edilmekte, katsayıların anlamlılık düzeyleri bootstrap yeniden örnekleme tekniği ile değerlendirilmektedir. Ölçüm modeli ise korelasyon temelli faktör yükleri üzerinden oluşturulmaktadır. Bu çerçevede PLS-SEM yaklaşımı, temelde OLS regresyonu, bootstrap yeniden örnekleme ve korelasyon analizlerine dayalı olarak uygulanmaktadır.

The Data Analysis Robot performs PLS-SEM analyses through a custom Python-based infrastructure developed using open-source libraries. Path coefficients in the structural model are estimated using Ordinary Least Squares (OLS), while their statistical significance is evaluated via nonparametric bootstrap resampling. The measurement model is constructed based on correlation-based factor loadings. Within this framework, the PLS-SEM approach is implemented primarily through OLS regression, bootstrap resampling, and correlation analyses.

Yapısal modelde yol katsayıları En Küçük Kareler (Ordinary Least Squares – OLS) yöntemiyle tahmin edilmekte, katsayıların anlamlılık düzeyleri bootstrap yeniden örnekleme tekniği ile değerlendirilmektedir. 🇬🇧 English

The Data Analysis Robot performs PLS-SEM analyses through a custom Python-based infrastructure developed using open-source libraries. Path coefficients in the structural model are estimated using Ordinary Least Squares (OLS), while their statistical significance is evaluated via nonparametric bootstrap resampling. The measurement model is constructed based on correlation-based factor loadings. Within this framework, the PLS-SEM approach is implemented primarily through OLS regression, bootstrap resampling, and correlation analyses.

Bu çalışmada yapısal model tahminleri Python açık kaynak altyapısında statsmodels.OLS kullanılarak gerçekleştirilmiştir. Yol katsayıları OLS yöntemiyle hesaplanmış; modelin açıklayıcılığı R² ve düzeltilmiş R² değerleri üzerinden değerlendirilmiştir. Sonuçlar SmartPLS çıktılarıyla tutarlılık göstermiştir. PLS-SEM Data Analysis Robot da yapısal model analizlerinde aynı OLS yaklaşımını temel almaktadır, bu da platformun metodolojik olarak geçerli ve güvenilir çıktılar ürettiğini göstermektedir.
Structural path estimations were conducted using statsmodels.OLS within an open-source Python environment. Path coefficients were estimated via Ordinary Least Squares (OLS), and model explanatory power was assessed using R² and adjusted R² values. The results were consistent with SmartPLS outputs. PLS-SEM Data Analysis Robot is also based on the same OLS approach, supporting its methodological validity and reliability.
